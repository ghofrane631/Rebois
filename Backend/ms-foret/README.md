# ms-foret

Microservice de gestion des forêts du projet Rebois.tn — expose les données de forêts, parcelles et points d'eau.
Port : **8082** | Base de données prévue : **PostgreSQL/PostGIS** (non câblée à ce stade).
Swagger UI : [http://localhost:8082/swagger-ui.html](http://localhost:8082/swagger-ui.html) | API Docs : [http://localhost:8082/v3/api-docs](http://localhost:8082/v3/api-docs).
Lancement : `mvn spring-boot:run` (depuis le répertoire `Backend/ms-foret`).
